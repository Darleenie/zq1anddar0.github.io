Govee

Checking Govee connection…

Govee has an official public API, so this connects directly — no hub, no tricks. The key is stored on the server and never shown again.

  1. Open the Govee Home app on your phone.
  2. Go to Profile (👤) → ⚙ Settings → Apply for API Key, fill in the short form.
  3. The key arrives by email within a few minutes.
  4. Paste it below and press Connect Govee.

Heads up: the Govee cloud API only exposes WiFi models. Bluetooth-only strips, sensors and thermometers won't appear unless they're paired through a Govee WiFi gateway.

Aqara & other Zigbee brands

Aqara devices speak Zigbee — a local radio protocol this web app physically can't reach from the cloud. They need a hub, but not a new integration: bridge them into SmartThings once and they appear in the device list above automatically.

  • Aqara hub (M2/M3/E1): SmartThings app → Add device → Partner devices → Aqara, sign in to your Aqara account — or pair via Matter if the hub supports it.
  • SmartThings hub: pair Aqara sensors directly to it over Zigbee (no Aqara hub needed).
  • Sengled → SmartThings via Sengled Hub integration.
  • Google Nest → SmartThings via Google Home cloud link.
  • Anything Matter-certified → pair with SmartThings and it shows up here.
